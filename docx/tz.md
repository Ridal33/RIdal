Техническое задание v1
 Проект: «Кофейня „Зерно“» — учёт заказов и остатков

 1. Назначение системы

Веб-система для автоматизации учёта заказов и остатков ингредиентов
в небольшой кофейне. Заменяет бумажные записи заказов и блокнот
с остатками.

 2. Цели и задачи

Цель: дать гостю возможность выбрать напиток и оформить заказ,
а бариста — видеть актуальные остатки и списывать ингредиенты
автоматически.

Задачи:
- вести меню напитков с рецептурами;
- принимать заказы и отслеживать их статусы;
- автоматически списывать ингредиенты по рецептуре;
- показывать актуальные остатки на складе;
- формировать отчёт по продажам за смену;
- разграничивать доступ по ролям.

 3. Функциональные требования

3.1. Роли и права
- гость — просмотр меню, оформление заказа;
- бариста — приём заказа, списание ингредиентов, просмотр остатков;
- владелец (администратор) — управление меню, пользователями, отчёты.

3.2. Меню
- список напитков с категориями;
- карточка напитка: название, цена, состав, рецептура;
- фильтры по категориям.

3.3. Заказ
- создание заказа бариста;
- статусы заказа: создан → готовится → выдан;
- автоматический расчёт стоимости.

3.4. Склад и остатки
- справочник ингредиентов с единицами измерения;
- рецептуры: расход ингредиента на порцию;
- автосписание при выдаче заказа;
- ручная корректировка остатков администратором.

3.5. Отчёты
- отчёт по продажам за смену: количество заказов, выручка;
- журнал операций по остаткам.

 4. Нефункциональные требования

- веб-интерфейс, работает в браузере;
- разграничение доступа по ролям;
- время отклика интерфейса — < 2 секунд;
- данные хранятся в реляционной БД.

 5. Ограничения

- реальные платёжные шлюзы не подключаются (оплата — симулятор);
- мобильного приложения нет — только веб;
- доставка не моделируется — заказ выдаётся на барной стойке;
- бухгалтерский и налоговый учёт не ведётся;
- интеграции с поставщиками и складским оборудованием нет.
